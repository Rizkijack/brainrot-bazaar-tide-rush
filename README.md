A 3D Roblox brainrot tycoon: collect absurd characters that earn money a second on your base, survive the Tide, repel raiders and rebirth for multipliers.

The game is built with Rojo and packaged for judging by a small Node 22 entry script.

## Run it

```sh
rojo build default.project.json --output game.rbxl
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
